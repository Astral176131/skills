# Awesome Claude Skills (index, not a skill)

Source: [travisvn/awesome-claude-skills](https://github.com/travisvn/awesome-claude-skills)

This is a curated **link list** of Claude/Claude Code skills and skill
collections — there's nothing to install from it directly, it's a directory
you browse to find other repos (several of which are already vendored
elsewhere in this repo: `anthropics/skills`, `obra/superpowers`,
`trailofbits/skills`, etc.).

## How to use it

Browse it when you want something not already in this repo:
https://github.com/travisvn/awesome-claude-skills

It's organized into:
- **Official Skills** (Anthropic's own — see `collections/anthropics-skills/`)
- **Community Skills Collections** (multi-skill repos like superpowers)
- **Individual Community Skills** (single-purpose skills — iOS testing,
  ffuf fuzzing, d3.js visualizations, scientific computing, etc.)
- **Community Tools** (meta-tools, e.g. converting docs sites into skills)

If you find something there you want vendored into this repo the way the
rest of these skills are, clone it into the matching category folder
(`general/`, `frontend/`, `security/`, `devtools/`, `collections/`) the same
way the others were done: keep the `SKILL.md`-containing directory, the
README, and the license; drop the source/tests/build tooling.
